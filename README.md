# Manzil.Pk — Hotel Booking Platform

A full-stack hotel booking platform focused on the Pakistani market, built to provide travelers with a simple way to discover, filter, and explore hotels across major destinations in Pakistan.

This project is being developed as part of an internship and is implemented progressively through development modules.



## Module 1 — Authentication & Hotel Discovery

**Status: Completed ✅**

Module 1 establishes the application's core backend architecture and hotel discovery experience.

### Completed Features

- User registration and login
- JWT-based authentication
- Protected API routes
- Role-based authorization
- Hotel listing APIs
- Hotel card UI
- City-based hotel filtering
- Rating-based filtering
- Hotel sorting
- Responsive hotel listing interface
- Pakistan-focused hotel data
- RESTful API architecture
